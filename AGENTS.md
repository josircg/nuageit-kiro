# Instruções do projeto Fila Clara

## Objetivo

Este é um projeto didático para aprender Kiro. Preserve o escopo de cada exercício e mantenha as práticas curtas e reproduzíveis.

## Regras universais

- Use JavaScript ESM compatível com Node.js 20 ou superior.
- Não adicione dependências sem justificativa e aprovação explícita.
- Preserve as funções de domínio puras; tempo deve entrar como argumento.
- Não altere testes existentes apenas para fazer uma implementação incorreta passar.
- Antes de editar, descreva causa ou resultado esperado e arquivos prováveis.
- Após editar, execute `npm test` e apresente o diff relevante.
- Não acesse rede, nuvem ou serviços externos neste projeto.
- Nunca leia, crie ou reproduza segredos. `.env` é proibido no Git.
- Não faça commit, push, merge ou exclusão sem solicitação explícita.

## Definição de pronto

Uma mudança está pronta apenas quando critérios de aceite estão ligados a testes, a suíte passa, o diff não contém alterações incidentais e o risco residual está registrado.
